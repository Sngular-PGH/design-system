# Documents (Word and Google Docs)

Guide for written documents — proposals, reports, briefs, SOWs, memos, written case studies — built from the official **Sngular Document Template**. Priority 4, after presentations, web, and apps. Unlike slides, these are edited by clients and people outside Sngular, so the rules favor compatibility over precision.

> Always start from the template. Never build a document from a blank file: the cover, back cover, header, footer, and styles live in it.

## Font

- **Verdana** for all body content — headings, paragraphs, tables, header. Outfit isn't reliably available in Word or Google Docs.
- **Outfit Light** only on the cover and back cover (title, date, closing tagline).
- Emphasis: **Verdana Bold**. No underline or italics, except quotes (Heading 6 style).

## Styles

| Style | Font / size | Color |
|---|---|---|
| Title / Heading 1 | Verdana 22pt | `navy` |
| Heading 2 | Verdana 18pt | `navy` |
| Heading 3 | Verdana 13pt | `navy` |
| Heading 4 | Verdana 12pt | `navy` |
| Links / table headers | Verdana 10pt Bold | `blue` |
| Quotes | Verdana 10pt Italic | `navy` |
| Body (Normal) | Verdana 10pt | `navy` |

## Color

Only `navy` (#061B2B), `navy-light` (#F2F3F4), `blue` (#0070F6), and `white`. No accent colors (`purple`, `green`, `red`) in documents.

## Tables

`blue` header row with white Bold text, `navy` Bold first column, alternating `navy-light`/`white` rows, white 0.5pt borders between cells.

## Cover and back cover

Full-bleed `navy`, giant S cut by a `blue` cursor, negative logotype. Cover title in Outfit Light 24pt white (≤30 characters, two lines max); back cover carries the `S|` isotype and the tagline "The unconventional, delivered."

## Page setup

A4 by default (a US Letter version is in review), 1.8cm left and right margins and 2.54cm top and bottom, different first page for the cover. The footer carries "Copyright © Sngular. All rights reserved." and the page number.

## Document types

| Type | Cover + back cover? |
|---|---|
| Proposal / SOW | Yes |
| Report (3+ pages) | Yes |
| Brief / memo | No |
| Case study (written) | Yes |
| Meeting notes | No |

## Delivery

Default to Google Docs when the piece stays internal; deliver .docx when the client asks for Word or the file leaves Google Workspace.

Full build spec — every style, table rule, and the brand team's decisions on the template — lives in the Sngular Design skill's `references/documents.md`.
