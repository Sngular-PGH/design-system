# Cover

Title card for the Sngular Design System itself: the first tile shown when the system is browsed. It isn't a React component — there's no `Cover` export in `bundle.js` or `index.d.ts` — so don't import it in products.

- Composition: the brand name in Outfit SemiBold with a one-line tagline, next to a block arrangement from the Brand Book page "La S" — the navy S hidden behind a `blue` cursor slab, a `navy-light` panel, a `navy` satellite block, and a single `green` accent (5%).
- Square corners (`radius-none`) and sizes in multiples of the spacing scale, like the rest of the system.
- For slide and document covers, use the cover layouts in `docs/01-presentations.md` and `docs/03-documents.md` instead.
