# Icon

Google Material Symbols icons in Outlined style, by name (fonts.google.com/icons).

- The page must load the font: `https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,300..400,0..1,0`.
- Weight 300 by default (or 400) and unfilled. 24px in UI and 48–64px in slides.
- Color: `ink`, `accent`, or a secondary accent (`purple`, `green`, `red`) in details.
- Decorative by default; pass `label` when the icon is the only signal.
