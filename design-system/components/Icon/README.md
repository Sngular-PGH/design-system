# Icon

Iconos de Google Material Symbols en estilo Outlined, por nombre (fonts.google.com/icons).

- La página debe cargar la fuente: `https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,300..400,0..1,0`.
- Peso 300 por defecto (o 400) y sin relleno. 24px en UI y 48–64px en slides.
- Color: `ink`, `accent` o un acento secundario (`purple`, `green`, `red`) en detalles.
- Decorativo por defecto; pasa `label` cuando el icono sea la única señal.
