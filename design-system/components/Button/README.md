# Button

Square button in Outfit SemiBold. *Derived for UI* from sngular.com.

- `primary` (blue): the view's main action; only one per view.
- `secondary` (navy border): alternative actions.
- `ghost` (blue text + `arrow_forward`): "Know more", "See more" in cards and lists.
- Text with a verb, in a short phrase, in the page's language ("Contact us", "Contáctanos").
- `onNavy` on navy backgrounds. Visible focus with a 2px `focus` ring.
- 48px (`md`) or 56px (`lg`) tall; touch target ≥ 44px.
