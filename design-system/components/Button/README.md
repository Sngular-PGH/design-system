# Button

Botón recto en Outfit SemiBold. *Derivado para UI* a partir de sngular.com.

- `primary` (blue): la acción principal de la vista; solo uno por vista.
- `secondary` (borde navy): acciones alternativas.
- `ghost` (texto blue + `arrow_forward`): "Know more", "See more" en tarjetas y listados.
- Texto con verbo, en frase corta y en el idioma de la página ("Contact us", "Contáctanos").
- `onNavy` sobre fondos navy. Foco visible con anillo `focus` de 2px.
- Altura 48px (`md`) o 56px (`lg`); área táctil ≥ 44px.
